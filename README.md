# MtaaFix

A fictional home repair service website for Mombasa, Kenya, built with HTML and CSS.

🔗 **Live demo:** https://nickelfrank110-hub.github.io/mtaafix-home-repairs/

## Features
- Sections for services, how it works, reviews, and why choose us
- Reusable card layout shared across sections
- Tappable phone and WhatsApp contact links
- Service request form with a dropdown and message box
- Descriptive alt text on all images

## Built With
- HTML5 (semantic elements, forms, images)
- CSS3 (reusable classes, box-sizing, focus effects)

## What I Practiced
- Reusing one `.card` class across many sections
- Building a page with images that scale on small screens
- Styling form fields, including select and textarea

## Note
This is a practice project. The form does not send data anywhere yet. Images are from Unsplash.
